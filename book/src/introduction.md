# Introduction

_ontoparse: a command line suite for working with ontology files_

## Motivation and scope

This project was originally developed to provide my lab members with a tool
to quickly extract cross-references between ontology terms (e.g., MESH --> MONDO).
Currently, this is all it does, however I plan to expand this tool as needed (e.g.,
to extract ID --> name maps, adjacency matrices, etc).
