# Install

## Pre-build binaries

### Installer scripts

#### macOS and Linux:

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/phicks22/ontoparse/releases/latest/download/ontoparse-installer.sh | sh
```

#### Windows PowerShell:

```bash
powershell -ExecutionPolicy Bypass -c "irm https://github.com/phicks22/ontoparse/releases/latest/download/ontoparse-installer.ps1 | iex"
```
